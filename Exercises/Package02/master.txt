Exercise 10 - Master Theorem Problems

Master Theorem Form:
T(n) = aT(n/b) + O(n^d)

Compare:
n^(log_b(a)) with f(n)


1. T(n) = T(n/2) + O(1)

a = 1
b = 2
f(n) = O(1)
n^(log_b(a)) = n^(log_2(1)) = n^0 = 1

f(n) = O(1), so this is Case 2.

T(n) = Θ(log n)


2. T(n) = 2T(n/2) + O(n)

a = 2
b = 2
f(n) = O(n)
n^(log_b(a)) = n^(log_2(2)) = n^1 = n

f(n) = O(n), so this is Case 2.

T(n) = Θ(n log n)


3. T(n) = 8T(n/2) + O(n^2)

a = 8
b = 2
f(n) = O(n^2)
n^(log_b(a)) = n^(log_2(8)) = n^3

f(n) = O(n^2), which is smaller than n^3, so this is Case 1.

T(n) = Θ(n^3)


4. T(n) = 2T(n/2) + O(n^2)

b = 2
