Worst Case Runtime Function

T(n) = 5floor(n / 2) + 5


We prove that T(n) ∈ Θ(n) by finding c1, c2, and n1 such that:

c1·n ≤ 5floor(n / 2) + 5 ≤ c2·n for all n ≥ n1


Constants

C1 = 2
C2 = 5
n1 = 2

Verification:

For n ≥ 2:

Lower bound: 2n ≤ 5floor(n / 2) + 5
This holds because the loop runs about n / 2 times in the worst case.

Upper bound: 5floor(n / 2) + 5 ≤ 5n
This holds for all n ≥ 2.


T(n) ∈ Θ(n)
