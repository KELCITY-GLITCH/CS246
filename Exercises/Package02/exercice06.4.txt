Worst Case Runtime Function

T(n) = 5n + 4


We prove that T(n) ∈ Θ(n) by finding c1, c2, and n1 such that:

c1·n ≤ 5n + 4 ≤ c2·n for all n ≥ n1


Constants

C2 = 6
n1 = 4

Verification:

For n ≥ 4:

Lower bound: 5n ≤ 5n + 4
: 4 ≥ 0, which holds for n ≥ 4

Upper bound: 5n + 4 ≤ 6n
: 4 ≤ n, which holds for n ≥ 4
